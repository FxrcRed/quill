Quill loads these fonts for its own process only (AddFontResourceEx FR_PRIVATE); nothing is installed system-wide.
Quill 启动时只给自己的进程加载这些字体，不装进系统。

NotoSansSC-Medium.otf / NotoSansSC-Bold.otf
  UI text (Chinese + Latin): Medium for body text, Bold for emphasis. 界面正文用 Medium、加粗用 Bold（Regular 在 Windows 上太细）。
  Noto Sans CJK SC, Copyright 2014-2021 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'.
  SIL Open Font License 1.1, see OFL-NotoSansSC.txt.
  Source: https://github.com/notofonts/noto-cjk (Sans/SubsetOTF/SC)

Michroma-Regular.ttf
